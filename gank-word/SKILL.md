# gank-word — 万人教育 Word 排版格式纠正

## 功能

对一份**已有的** `.docx` 文件，自动纠正为万人教育的标准排版格式。只改格式，不碰内容。

核心能力：
- 修改 Word 内建样式定义（字体/字号/颜色/间距/对齐）
- 全文扫描标题层级并自动纠偏（缺一级就整体上移）
- 识别"解析"段落（以【万人教育解析】开头）：标签 run 用华文新魏，正文继承正文样式（宋体）
- 清除所有自动编号
- 设置页眉/页脚距边界距离

## 使用方法

用户提供要修正的 `.docx` 文件路径后，运行脚本：

```bash
python <skill-dir>/scripts/format_docx.py input.docx -o output.docx
```

省略 `-o` 参数则覆盖原文件。脚本用纯 Python 标准库（zipfile + xml.etree），无外部依赖。

## 排版规范速查

| 元素 | 中文字体 | 西文字体 | 字号 | 其他 |
|---|---|---|---|---|
| 目录标题 | 华文新魏 | Times New Roman | 48pt | 居中，不加粗，黑色 |
| 目录条目 | 宋体 | Times New Roman | 原始字号 | 不加粗，保留原始缩进和制表位 |
| 一级标题 | 宋体 | Times New Roman | 三号(16pt) | 加粗，居中，段前17.5磅，段后16磅 |
| 二级标题 | 宋体 | Times New Roman | 小三(15pt) | 加粗，左对齐，1.5倍行距 |
| 三级标题 | 宋体 | Times New Roman | 四号(14pt) | 加粗，左对齐，1.5倍行距 |
| 正文 | 宋体 | Times New Roman | 小四(12pt) | 两端对齐，1.5倍行距 |
| 页眉 | 华文新魏 | Times New Roman | 五号(10.5pt) | 居中；距边界1.3cm |
| 页脚 | 华文新魏 | Times New Roman | 五号(10.5pt) | 居中；距边界0.9cm |
| 解析 | 华文新魏（仅标签）/ 宋体（正文） | Times New Roman | 小四(12pt) | 段落用 Normal 样式，黑色 |

所有元素颜色均为黑色。

## 标题层级纠正规则

1. 扫描全文，找出实际使用的最浅标题级别
2. 如果最浅不是一级，整体上移（比如文档全是二级+三级 → 变成一级+二级）
3. 全文统一做一次偏移，不按章节分块
4. 超出三级的标题降为正文样式

判断依据：优先看 Word 标题样式名/outlineLvl，不看文字中的序号。

## 注意事项

- 脚本不处理内容层面的要求（比如"选择题解析要写原因"这类）——那属于内容审查，不归排版管
- 如果文档里某些段落被错误标为标题但实际不是标题（比如被手动设了 Heading 样式的正文段落），脚本会按现有标记处理。建议用户先通读确认标题标记大体正确
- 「目录」标题的识别优先看样式名（TOC Heading / 目录标题）；仅当段落文本恰好等于「目录」、且不是列表项、也不在表格或文本框内时，才用文本兜底
- 标题层级偏移是全局的、按整篇一次偏移：同一个四级标题，在"文档里有更浅级标题"时会被降为正文，在"整篇从四级起"时会被提升为一级
- 运行后建议用 Word 或 WPS 打开检查一下视觉效果
